Text Extraction (OCR)

Extract text from screenshots before sending to AI. This reduces token usage and speeds up responses for text-heavy screenshots.

computer OCR Active (LM Studio Mode)

science Test OCR

How it works

  • photo_camera Take a screenshot as usual
  • search Text is automatically extracted using Tesseract OCR
  • edit_note Extracted text is added to your prompt
  • rocket_launch AI receives text context (faster, cheaper responses)

Note: First OCR operation may take a few seconds to download the language model (~2MB).
