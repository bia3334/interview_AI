mic Voice Transcription

Press Ctrl/Cmd+Shift+V to record system audio (e.g. a Zoom interviewer) plus a screenshot, then auto-send to your AI providers. Uses the API key for the selected provider.

Whisper needs an OpenAI key. Gemini needs a Gemini key. Set them on the Models tab.
Used by both Exam voice capture and Interview live listening. Pin a language if auto-detect mixes them up on short phrases.

hearing Interview Listening

How Interview mode turns the call audio into text. You can also switch this from the Interview toolbar.

Standard waits for a pause, then transcribes the sentence (~2–4 s to the answer). Realtime streams audio continuously with server-side turn detection (~1–2 s), and costs a little more per minute.
Only gpt-live-transcribe shows partial words live; the gpt-4o models wait for the server to detect a pause and then return the whole sentence.
Region sends less data to the AI, which can be faster and more accurate, but requires you to drag a selection after stopping the recording.

document_scanner Text Extraction (OCR)

Extract text from screenshots before sending to AI. This reduces token usage and speeds up responses for text-heavy screenshots.

computer
OCR is on (LM Studio mode). LM Studio is text-only, so screenshots are converted to text automatically. Managed for you while LM Studio is active.
Select the primary language in your screenshots for better accuracy.

science Test OCR

Take a screenshot first, then click "Test OCR" to preview extracted text without sending to AI.

Confidence: {{ ocrTestResult.confidence.toFixed(0) }}% {{ ocrTestResult.text.length }} chars 
{{ ocrTestResult.text }}

How it works

  • photo_camera Take a screenshot as usual
  • search Text is automatically extracted using Tesseract OCR
  • edit_note Extracted text is added to your prompt
  • rocket_launch AI receives text context (faster, cheaper responses)

Note: First OCR operation may take a few seconds to download the language model (~2MB).

touch_app Window Behavior

By default, after pressing Ctrl/Cmd+Shift+A to hide and re-show the window, you have to press Ctrl/Cmd+Shift+W again to make it clickable. Turn this on so the window is interactive automatically whenever it appears.

When off (default): the window starts in click-through mode after every show; press Ctrl/Cmd+Shift+W to interact.
When on: every show makes the window immediately clickable. You can still press Ctrl/Cmd+Shift+W to toggle back to click-through.
